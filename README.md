# 模型目的(purpose)
因應氣候與環境劇烈變化開始永續能源發展，而氫能發電是當前臺灣再生能源的發展主力之一，在畜牧場設置氫氣燃料電池，是一種將將氫氣與氧氣反應，過程不經燃燒，產生電能並只產生純淨的水。實現淨零碳排放的發電。此外氫能發電機組還具有高效能轉換、儲能容易、綠色環保等特點，也建立太陽能光電設施，不僅具發電效益，亦有降溫效果，在白天所發出來的電量提供畜牧場並將多餘的電力透過產氫機台電解水生產綠氫儲存，利用 AI模型預測出畜牧場的耗電高峰及時發電，達成削峰填谷作用，降低畜牧場的電費成本，並解決高峰時段電力緊張的問題。這不僅提升了能源利用效率，也對環境保護和永續發展起到了積極作用。
# 模型用途(usage)
當預測模型發現電力不足時(耗電量超過發電量)，模型能提早透過系統示警提醒氫能系統發電(將儲能氫氣轉化為電力)，避免畜牧試驗場因電力不足而導致產能下降。
# 模型價值(value)
利用白天太陽能多發的餘電，在用AI預測出用電高峰將多餘電產氫儲能發電，達成削峰填谷作用，每年可減少約13.2噸碳排放，提供2.4萬度綠電。
